ThingsBoard / Backend Only

Hướng Dẫn Riêng Cho Các Mode No UI

Trang này chỉ tập trung vào các mode giúp backend không serve embedded UI, hoặc đi xa hơn là build/package mà không kéo ui-ngx vào runtime classpath của application.

Note quan trọng: full UI vẫn là hành vi mặc định. Bạn không cần sửa tay application/pom.xml để bật lại UI. Chế độ no-ui chỉ xuất hiện khi bạn chủ động dùng config Backend Only, No UI, hoặc Maven option -P!embedded-ui.

1. Các Mức "No UI"

Mode Cơ chế Mức tách UI Khi nào dùng
backend-only Tắt static mapping và tắt SPA forward controller Backend không serve UI, nhưng runtime classpath vẫn có thể còn ui-ngx Debug backend nhanh, FE chạy riêng bằng yarn start
-P!embedded-ui Tắt Maven profile kéo dependency runtime ui-ngx ui-ngx không còn trong runtime/package classpath của application Khi muốn backend-only rõ ràng hơn, package sạch hơn

2. Các Run Config Liên Quan

TB - Monolith Fast (Backend Only)

Kiểu IntelliJ Application. Nhanh nhất cho monolith backend-only. Dùng profile backend-only.

TB - Core Fast (Backend Only)

Kiểu IntelliJ Application. Dành cho tb-core microservices mode nhưng không serve UI.

TB - Monolith Local (No UI Runtime)

Kiểu Maven. Dùng -P!embedded-ui và profile backend-only.

TB - Monolith Package (No UI)

Kiểu Maven package. Build backend package mà không kéo ui-ngx runtime.

TB - Core Package (No UI)

Kiểu Maven package. Build theo hướng core/no-ui để kiểm tra artifact backend-only.

3. File Và Cấu Hình Liên Quan

Profile backend-only

File:

application/src/main/resources/thingsboard-backend-only.yml

Nó đang bật:

ui.embedded.enabled: false
spring.web.resources.add-mappings: false

Tắt SPA forward controller

WebConfig chỉ còn active khi:

ui.embedded.enabled=true

Tắt runtime dependency ui-ngx

Trong application/pom.xml, dependency ui-ngx đã được chuyển vào profile Maven:

<profile>
  <id>embedded-ui</id>
  <activation>
    <activeByDefault>true</activeByDefault>
  </activation>
  ...
</profile>

Tức là muốn loại nó khỏi runtime/package thì dùng:

-P!embedded-ui

4. Nên Dùng Mode Nào

Tình huống Khuyên dùng
Debug backend monolith nhanh, FE chạy riêng TB - Monolith Fast (Backend Only)
Debug microservices core nhanh, không cần UI embedded TB - Core Fast (Backend Only)
Muốn verify Maven runtime không kéo ui-ngx TB - Monolith Local (No UI Runtime)
Muốn build artifact/package backend-only TB - Monolith Package (No UI) hoặc TB - Core Package (No UI)

5. Workflow Gợi Ý Khi Dev FE

  1. Chạy backend bằng TB - Monolith Fast (Backend Only).
  2. Chạy frontend bằng TB - UI NGX Dev hoặc cd ui-ngx && yarn start.
  3. Mở http://localhost:4200 để làm việc với hot reload.
  4. Không dùng UI ở http://localhost:8080.

6. Lưu Ý Thực Tế

  • Mode backend-only giúp backend không trả UI embedded, nhưng RAM giảm thường chỉ ở mức vừa phải.
  • Nếu muốn tách runtime rõ ràng hơn, hãy dùng các config có No UI Runtime hoặc Package (No UI).
  • Quan trọng: các config Maven package/build theo -P!embedded-ui vẫn có thể mất thời gian vì còn build backend modules phụ thuộc, chỉ là không kéo UI runtime vào artifact của application.
